# 造火箭控制台 · 上手指南

这一个页面就是 **和猫娘一起造火箭（SFS）** 插件的驾驶舱。

插件在 N.E.K.O. 的插件页面里会开一个叫「造火箭控制台」的面板，
不用进对话也能看遥测、看画面、点游戏按钮、按着键转向、载入蓝图、改设置。
想用嘴指挥猫娘也行 —— 面板和她调的是同一批能力，两边不会打架。

> 第一次用请先看仓库里的 [使用教程](../../使用教程.md)：那里有完整的装模组步骤、
> 「你想做什么 → 可以这样说」的对照表，以及常见问题。本页只讲面板。

---

## 一分钟上手

1. **装好游戏模组**（必须）：把 `SFS-Agent.dll` 放进
   `<Steam>\steamapps\common\Spaceflight Simulator\Spaceflight Simulator Game\Mods\SFS-Agent\`，
   然后**重启游戏**。模组只在游戏启动时加载。
2. **启动插件**：N.E.K.O. → 插件页面 → 启动「和猫娘一起造火箭(SFS)」。
3. **打开面板**：插件页面里的「造火箭控制台」。

面板右上角的徽章就是当前状态：

| 徽章 | 含义 |
| --- | --- |
| 主菜单 / 加载中 | 连上了，但还没进世界（游戏停在主菜单） |
| 建造场景 | 在建造界面，可以载入蓝图、放零件 |
| 飞行中 | 有飞行器，遥测和飞行控制都可用 |
| 未连接 | 连不上桥接服务 —— 按下面「连不上怎么办」排查 |
| 插件未启动 | 插件本体没跑，先去插件页面启动它 |

## 六个页签分别干什么

### 总览
连接状态、往返延迟、飞行遥测（高度 / 速度 / 油门 / 当前分级 / 总质量 / 所在天体）、
轨道根数（远点、近点、离心率、周期）、当前火箭构成、按住中的按键。

「自动刷新」默认开着，每 4 秒读一次。跟猫娘对话时嫌吵可以关掉。
一眼看数据用这个页签就够了。

### 画面
点「抓取画面」把游戏当前画面抓下来显示在面板里。
**这个画面只是给你自己看的**，不会自动送进模型 —— 想让猫娘看图，直接对她说
「你看我造的火箭」「看看我现在飞到哪了」，她会自己调 `see_sfs_screen`。

### 界面
游戏里所有**可点击的按钮**列成一张表（按钮文字 + 屏幕位置）。
点表格里的一行 = 点击那个按钮。

- 点击是**游戏内事件派发**：不会移动你的鼠标，游戏窗口也不用切到前台，
  你可以一边用电脑做别的事。
- 但它**会真实改变游戏状态**（开始游戏、载入存档、改设置），点之前想清楚。
- **游戏切场景很慢**：点完等几秒再看新列表。按钮没变化不等于没点上，
  连续两三次都一样才算操作无效。
- 界面是分级的：进存档列表后要先点一张存档卡片，
  `Play / Rename / Delete` 才会从灰色变可用（灰的会被自动过滤掉）。

也可以按序号或按 0-1 坐标点击（左上角是 (0,0)，右下角是 (1,1)）。
序号比坐标可靠。

### 飞行
- **油门**：拖动滑块后点「设为 N%」，走的是游戏内指令，不经过键盘，最可靠。
- **飞行指令**：点火、熄火、执行下一级（空格）、分级控制程序（回车）、RCS 开关。
- **按键**：转向（Q/E）、RCS 平移（W/A/S/D），每个键都有「点动」和「按住」两种。
- **视角**：拉近、拉远、左右转 15°。

> ⚠️ **转向和 RCS 平移是持续推力**：只点一下几乎没效果。
> 正确姿势是「按住」→ 看遥测 → 「松开」。**忘了松开会一直朝那个方向加速** ——
> 所以面板上有一个显眼的「全部松开（急停）」。
> RCS 平移还要先按 `R` 打开 RCS 才有效。

### 建造
- **载入蓝图（推荐）**：选一个自己存过的设计，整枚加载进建造台。
  蓝图里每个零件的尺寸、纹理、分级都由游戏自己解析，所以坐标一定正确、一定能飞。
- **单个零件（不推荐）**：从零件目录里选一个，给网格坐标放置。
  手拼要算贴合点间距，算错就装不上；拼错了发射时上面的零件会掉下来把火箭砸爆。

### 设置
桥接地址、超时、截图参数、视觉识别开关与提示词、
以及可选的「自带视觉模型」（OpenAI 兼容接口）。
保存后**立即生效，不用重启插件**。

两点注意：

1. **改端口要改两处**：这里的「桥接地址」和模组侧的 `sfs-agent.ini`。
   只改一处，两边就对不上了。
2. **API Key 只写不读**：面板只会告诉你「已配置 / 未配置」，不会回显密钥。
   Key 输入框留空 = 保持原值不变，不会把已有的密钥清掉。

## 高级：Agent 独占模式

在「飞行」页签底部。开启后，游戏**忽略你自己的鼠标与键盘**，只接受猫娘派发的输入。
只有在你完全把操作交给猫娘时才开。

**应急解除**：在游戏里按 `F10`，或者回到面板把这个开关关掉。

---

## 连不上怎么办

面板报「连不上游戏桥接服务」时，按顺序查：

1. **游戏在运行吗？** 桥接服务是游戏内的模组开的，游戏没开就一定连不上。
2. **模组装对位置了吗？** 必须是 `Mods\SFS-Agent\SFS-Agent.dll` 这种
   **一目录一模组**的形式，文件名要和目录名一致。
3. **装完模组重启过游戏吗？** 模组只在游戏启动时加载。
4. **有没有两个模组抢端口？** 旧模组目录没删干净时，连上的可能不是你期望的那个。
5. **端口对得上吗？** 模组侧 `sfs-agent.ini` 里的 `port` 要和面板里的桥接地址一致。
6. **游戏窗口被最小化了吗？** 截图需要游戏渲染一帧，最小化时抓不到。

排查完点「检测连接」重试即可。

---

## 它不会瞎编

遥测读不到时，插件会明确说「游戏可能没有运行，请如实告诉用户，不要编造飞行数据」，
而不是编一组好看的数字。画面抓不到、视觉模型不可用时也一样会如实说明。

《航天模拟器》不是真实尺度（地球半径约 315 km、大气层顶约 30 km 上下，
而且支持自定义星系包）—— **任何数值都从遥测里读，不要拿现实常识套**。
